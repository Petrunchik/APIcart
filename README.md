# API интернет-магазина на FastAPI

## Описание

Разработан API интернет-магазина на FastAPI с использованием асинхронной работы с базой данных PostgreSQL через AsyncSession, SQLAlchemy и драйвер asyncpg.

Проект охватывает ключевые функциональности для управления пользователями и товарами, с акцентом на безопасность и удобство тестирования.

Реализована система регистрации пользователей, аутентификации через JWT и управления товарами с проверкой ролей.

---

## Реализованные функции

### Регистрация и аутентификация:

- Реализован эндпоинт **POST /users/** для создания пользователей с ролями "seller" и "buyer"
- Настроен **POST /users/token** для выдачи JWT-токенов:
  - `access_token` (30 минут)
  - `refresh_token` (7 дней)
- Реализована аутентификация через **OAuth2PasswordBearer** с использованием логина и пароля

### Управление товарами:

- Созданы эндпоинты (**POST /products/**, **GET /products/**, и другие) для CRUD-операций с товарами
- Реализована проверка роли "seller" через `get_current_seller` с привязкой товаров к продавцу (`seller_id`)

### Обновление токена:

- Создан эндпоинт **POST /refresh-token** для обновления `refresh_token`
- В рамках домашнего задания реализован эндпоинт, принимающий `refresh_token` и возвращающий новый `access_token`

### Безопасность:

- Реализована проверка активности пользователей (`is_active == True`) при аутентификации и обновлении токена
- Используется **SECRET_KEY** для подписи и валидации JWT

---

## Полученный опыт

### Асинхронное программирование:

- Применен **AsyncSession** с использованием **await** для выполнения запросов к базе данных (`db.scalars`, `db.commit`, `db.refresh`)
- Освоены методы предотвращения ошибок, таких как **AttributeError**, возникающих при отсутствии `await`

### Аутентификация и авторизация:

- Настроен **OAuth2PasswordBearer** для выдачи и проверки JWT-токенов
- Реализована система ролей (`role` в JWT) и проверка прав доступа (`seller_id`)

### Тестирование API:

- Проведено тестирование функциональности через **Swagger UI**
- Освоены методы проверки различных сценариев работы API с использованием интерактивной документации
